# Security Policy

## Supported Versions
Traceback actively maintains security updates on the latest release branch:

| Version | Supported          |
| ------- | ------------------ |
| 1.3.x   | :white_check_mark: |
| < 1.3.0 | :x:                |

## Reporting a Vulnerability
We take the security and privacy of our users extremely seriously. If you discover a potential security flaw, PII leakage edge case, or vulnerability in Traceback:

1. **Do NOT open a public GitHub issue.**
2. Send a detailed report to our security maintainers at: `security@traceback.app` (or open a private GitHub Security Advisory).
3. Include:
   - Steps to reproduce the issue.
   - Sample payload or message triggering the flaw.
   - Any proposed remediation or patches.

We acknowledge reports within 48 hours and work with you on responsible coordinated disclosure.
