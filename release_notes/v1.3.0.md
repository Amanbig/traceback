# Release v1.3.0

**Release Date:** November 22, 2026  
**Codename:** *Bharat Cyber Shield & Multi-Regional Forensics*

### 🌟 Key Highlights
- **Multi-Regional Indian Vernacular Support (8 Languages)**:
  - Added full vernacular translation across **English, Hindi (हिंदी), Tamil (தமிழ்), Telugu (తెలుగు), Bengali (বাংলা), Marathi (मराठी), Gujarati (ગુજરાતી), and Kannada (ಕನ್ನಡ)**.
  - Generates localized emergency recovery playbooks and statutory 1930 / bank freeze advisories directly in the victim's mother tongue.
- **Dynamic Hybrid AI via Firebase AI Logic SDK**:
  - Configured zero-leakage client-side PII scrubbing prior to cloud inference.
  - Dynamically escalates scrubbed snippets to **Google Gemini** in the cloud.
  - Seamless automatic fallback to local Gemini Nano / heuristic triage if the user is offline or connection drops.
- **Enhanced On-Device Threat Classifier (RAT & Multi-Vector Taxonomy)**:
  - Deep local heuristics for Remote Access Trojans (AnyDesk, RustDesk, malicious sideloaded APKs).
  - Indian cyber fraud vectors: Digital Arrest impersonation, UPI reverse PIN scams, electricity night-time disconnection panic, and fake traffic e-challans.
- **Hardened PDF Forensic Evidence Dossier**:
  - One-tap browser file download on web and native share sheet on mobile.
  - Tamper-proof SHA-256 chain of custody checksum and statutory FIR / bank dispute annexure.
- **Theme Mode Switcher**:
  - User-configurable Dark Mode, Light Mode, and System Synchronization under Settings.
